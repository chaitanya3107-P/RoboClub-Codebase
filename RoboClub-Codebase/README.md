# RoboClub-Codebase
Official code repository of RoboClub, containing firmware, embedded systems code, and robotics projects built using Arduino, ESP32, sensors, motor drivers, and other hardware. Includes code for line followers, maze solvers, RC robots, robotic arms, and competition bots.
 
15th August: ARM & JAW code, chassis code.

COEP Mindspark 26: Maze solver, line-following files, PPT resources.

Line Follower: Line-following robot codes.

Maze Solver: Obstacle-avoidance code.

Robo Rumble 2.0: Circuit images, PPT, RoboSoccer code.

Robotic Dog: Project files.

Rulebooks: Competition rulebooks.

URC: Competition-related resources.

AISSMS: Race-bot code.
